    Add-ons / Evolutionary Magick

    Electrify Path

    These are the Electrify Path spells of the Amar Evolutionary Magick System.

    Spell Description Requirements
    Rank 1
    Glowing Sparks Creates small glowing sparks in the area of effect, the glowing sparks gives out the same brightness as torches.
    Rank 2
    Igniting Spark Creates a spark that ignites that can help spread or start a fire, as long as you have a stronger source of energy. At level three, the spell can set an ignitable object on fire.
    Rank 3
    Electric Glare The caster summmons a spark that is only visible for the targeted creature, the targeted creature will be blinded and get -1 per every other level, starting with one, in combat stats next turn.
