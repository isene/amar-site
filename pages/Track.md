---
title: Track
categories:
- Perception Skills
- Skills
---

Whenever a character wishes to follow some tracks, a tracking roll is made. One roll is made per 100 meters of tracking. Difficulty ratings in different terrains are shown in the table.

| DR  | Terrain                                           |
|-----|---------------------------------------------------|
| 1   | Snow                                              |
| 2   | Marsh-like surface                                |
| 3   | Soft soil / sand                                  |
| 6   | Soil                                              |
| 8   | Much underbrush                                   |
| 10  | Normal underbrush                                 |
| 14  | Some underbrush                                   |
| 18  | Grass (cut)                                       |
|     | **Other**                                         |
| +1  | Per try if no success                             |
| +1  | Per day of ordinary weather                       |
| –1  | Per 5 in size of the creature(s) you are tracking |
