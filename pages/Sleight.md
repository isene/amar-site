This skill is used in situations requiring manual dexterity and swift hands. It is often used to pick pockets. The modifiers in the table below are added to your skill and a dice roll. The victim then has to make an awareness roll exceeding this to notice it.

**Pick Pockets**

| Mod. | Circumstances                  |
|------|--------------------------------|
| –9   | Inside jacket in shirt pocket  |
| –6   | Inside jacket                  |
| –3   | Pants                          |
| –1   | Pants, back pocket / cut purse |
| +1   | Baggy pants, back pocket       |
| +3   | Jacket pocket                  |
| +4   | Baggy jacket pocket            |
| +6   | Closed backpack                |
| +7   | Open backpack                  |
