---
title: Climb
categories:
- Physical Skills
- Skills
---

One climb roll is made for every 5 meters of climbing. If the roll is not successful, the character is stuck. A second attempt may be made, but if this second roll fails, the character falls down. If the roll fails by more than 5, the character falls down. Difficulty ratings and adjustments are:

| DR  | Action                                              |
|-----|-----------------------------------------------------|
| 0   | Easy tree / very easy cliff wall                    |
| 3   | Normal tree / cliff wall with easy grips            |
| 6   | Difficult tree / a rope / a cliff wall              |
| 9   | A thin rope / a hard cliff wall / a castle wall     |
| 12  | A stem only / a difficult castle wall               |
| 15  | A slippery stem only / a very difficult castle wall |
| –3  | With rope / wall                                    |
| +6  | Slippery (max. adjustment)                          |
